# Workspace Rules

## Premium Portfolio UI/UX Guidelines
When building or refactoring portfolio websites, strictly adhere to these premium design principles:
1. **Layout & Width**: Avoid split 50/50 empty-space layouts (like traditional alternating timelines). Prefer a focused, centered single-column layout where the main content card occupies ~70% of the screen width (`max-w-4xl` to `max-w-5xl`).
2. **Timeline Style**: If using a timeline, keep the vertical line tight to the left side of the card, avoiding giant empty gaps. Everything should feel compact and centered.
3. **Typography Scale**: Use extreme contrast in typography for a premium feel:
   - Main Headers: Very large (72px - 80px, `text-6xl` or `text-7xl`).
   - Subtitles/Company Names: Medium (22px, `text-xl`).
   - Card Titles: Large (34px, `text-3xl` or `text-4xl`).
   - Body/Bullets: Readable (18px - 19px, `text-lg`).
4. **Content Density (Less is More)**: When listing experience or project features, limit bullet points to a maximum of 5 highly impactful, concise sentences. Recruiters skim quickly—do not overwhelm them with 8+ bullet points.
5. **Card Anatomy**: Use subtle internal dividers (`border-t`) to separate core technologies, bullet points, and infrastructure/deployment tech.

## Resume Experience Calibration
When drafting or editing resume bullet points, always calibrate the breadth of technologies and scope of responsibilities to match the user's stated years of experience (1-1.5 years). Avoid keyword stuffing (do not list too many competing frameworks like React + Angular or cloud providers AWS + Azure).
